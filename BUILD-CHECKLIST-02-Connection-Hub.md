# ✅ Gather Build Checklist — Room 2: Connection Hub

Build this **second**, right after [Main Spawn](BUILD-CHECKLIST-01-Main-Spawn.md). It's the transport
center every other space connects to. Keep the **3D prototype's Campus Hub open next to you as the
picture** (central fountain/gateway, ring of labeled portals, directory sign, benches and lamps).

Each line is one action in the Gather **Mapmaker**. Tick them off as you go.

> Why second: once this room exists you can come back to Main Spawn step **I** and finish the
> Spawn → Hub portal. From here the whole universe branches out.

---

## A. Open the builder
- [ ] In the Mapmaker tab (or reopen: space → **Build (hammer)** → **Edit in Mapmaker**).
- [ ] Confirm you're still signed in as **Builder/Admin** and the client stays **Owner**.

## B. Create the room
- [ ] **Rooms list** (lower-right) → **+ Add a room** → name it exactly **`Connection Hub`**.
- [ ] When asked for a size, choose **Blank**, about **30 × 22 tiles** (you can resize later).

## C. Floor (the plaza)
- [ ] Top tabs → **Walls & Floors** → **Floors**.
- [ ] Pick a **marble / plaza** tile (a touch grander than Main Spawn — this is the hub).
- [ ] Paint the whole room with it (click-drag).
- [ ] (Optional) **Objects** → search **`rug`** → place a round rug in the **dead center** under the centerpiece.

## D. Centerpiece — the Expansion Gateway
- [ ] **Objects** → search **`fountain`** (or **`globe`** / **`portal`**) → place **1** in the exact center.
- [ ] This is the "Expansion Gateway" — the visual heart visitors orient around.
- [ ] **Tile Effects** → **Impassable** → stamp the fountain tiles so avatars walk around it.

## E. Objects (the plaza furniture)
Use **Objects** tab → search each term → click to place. Ring them around the centerpiece:
- [ ] `bench` × 4 — one on each side, facing the fountain.
- [ ] `lamp` (or `street lamp`) × 4 — evenly spaced around the ring.
- [ ] `potted plant` (or `plant`) × 2 — flanking the directory.
- [ ] `directory` (or `bulletin board`) × 1 — set against the top wall = the **wayfinding directory**.
- [ ] After placing, add **Impassable** tiles over the lamps and the directory (Tile Effects).

## F. The directory (interactive wayfinding)
- [ ] Double-click the **directory / bulletin board** → **Object Interactions** → **Note** → paste:
  > *Connection Hub — your map to the universe. ✦ Main Spawn (south) · Common Ground (west) ·
  > Community HQ (east) · Have a Seat Legacy Hall (NE) · PTI Legacy Hall (NW) · Outdoor Areas (SW) ·
  > Beach & Park (SE). Step through any glowing portal to travel.*
- [ ] (Optional) add a second board → **Embedded website** = a public Google Calendar embed =
      the **Live Events Calendar** kiosk. *(If it "refuses to connect," use a Note + link instead.)*

## G. Future-expansion gateway nodes
- [ ] **Objects** → search **`portal`** / **`pad`** → place **2–4 decorative pads** near the edges.
- [ ] Double-click each → **Note** → paste:
  > *Reserved gateway — future universe expansion (coming soon).*
- [ ] These satisfy the "access point for future expansions" brief **without** building those worlds yet.

## H. The 7 portals — placement
Lay out **7 exit points** around the plaza ring, one per destination. Leave each on **open floor**
(not on a bench/lamp/fountain). For each, first place the look, then the portal tile in step **I**:
- [ ] `arch` / `gate` / `door` object on each of the 7 spots (Objects → search `arch`).
- [ ] A small `sign` (or `signpost`) next to each arch → **Note** with just the destination name
      (e.g. *"→ Common Ground"*). This is the labeled-portal unit — build one, **copy-paste** the rest.

## I. The 7 portals — wire them up
*(Stamp these as the destination rooms get built. **Main Spawn already exists**, so do that one now;
come back for the others as you build each room. Every portal is a **round-trip**.)*

**Steps for each:** **Tile Effects** → **Portal** → stamp the arch tile → pick the destination **Room**
→ click its **exit tile** → then build the **return** portal in that room back to here.

- [ ] Portal → **Main Spawn**  *(do now — then finish Main Spawn step I: its arch → Connection Hub)*
- [ ] Portal → **Common Ground**
- [ ] Portal → **Community Headquarters**
- [ ] Portal → **Have a Seat Legacy Hall**
- [ ] Portal → **PTI Legacy Hall**
- [ ] Portal → **Outdoor Community Areas**
- [ ] Portal → **Beach & Park**

> Place each **return** portal next to a clear tile (not on furniture or another portal) so avatars
> don't instantly bounce back.

## J. Save & test
- [ ] Top nav → **Save**.
- [ ] From **Main Spawn**, walk through the arch → you should arrive in the **Connection Hub**.
- [ ] Press **X** on the directory → the wayfinding Note opens.
- [ ] Walk back through the Hub→Spawn portal → you should land back in Main Spawn (round-trip works).
