# ✅ Gather Build Checklist — Room 8: Beach & Park

Build this **eighth and last** for Phase 1, after [Outdoor Community Areas](BUILD-CHECKLIST-07-Outdoor-Community-Areas.md).
It's the relaxed shoreline — a central-park-style beach for calm, low-pressure socializing, and the
**strong closing shot** for the client demo. It closes the outdoor loop (Outdoor ↔ Beach). Keep the
**3D prototype's Park / beach scene open next to you as the picture**.

> *"Simple beach/park additions if approved"* — confirm with the client that this room is in scope
> before building it.

Each line is one action in the Gather **Mapmaker**. Tick them off as you go.

---

## A. Open the builder
- [ ] In the Mapmaker tab, signed in as **Builder/Admin** (client stays **Owner**).
- [ ] Confirm the **client has approved** the beach/park additions.

## B. Create the room
- [ ] **Rooms list** → **+ Add a room** → name it exactly **`Beach & Park`**.
- [ ] Choose **Blank**, about **40 × 16 tiles** — a **long horizontal strip** (much wider than
      tall). The park reads as a **line running left → right**, not a tall block.

## C. Floor (sand + sea)
- [ ] **Walls & Floors** → **Floors** → **sand** → paint the whole room.
- [ ] Pick a **water** floor → paint a **sea edge** along **one full side** of the room.
- [ ] **Tile Effects** → **Impassable** → stamp **every water tile** (the shoreline is a wall of sea).
- [ ] Pick a **boardwalk / wood path** floor → paint a path along the sand parallel to the water.

## D. Beach objects
Use **Objects** → search **"beach" / "summer" / "park"** → click to place:
- [ ] `palm tree` × 4 — along the boardwalk and corners.
- [ ] `beach umbrella` × 3 and `bench` × 2 — the lounge spots (build one umbrella+bench set, copy-paste).
- [ ] `sandcastle` × 2, `flag` × 1, `flower` × 2.
- [ ] (Optional, for life) `volleyball` / `towel`.
- [ ] **Tile Effects** → **Impassable** → stamp over palms and umbrellas.

## E. Relaxed sign (interactive)
- [ ] **Objects** → `sign` → place near the boardwalk.
- [ ] Double-click → **Object Interactions** → **Note**: *"A relaxed, central-park-style shoreline —
      pull up a seat and enjoy the calm."*

## F. Portals (close the outdoor loop)
*(Round-trips. Build a `door`/`arch` on each portal tile.)*

**Steps:** **Tile Effects** → **Portal** → stamp tile → destination **Room** → click exit tile →
build the **return** portal back here.
- [ ] Portal ⇄ **Connection Hub**
- [ ] Portal ⇄ **Outdoor Community Areas**  *(completes Outdoor's pending Beach link)*

## G. Save & test
- [ ] Top nav → **Save**.
- [ ] Portal in from the Hub; confirm the **sea edge is solid** (can't walk into the water).
- [ ] Press **X** on the relaxed sign → Note opens.
- [ ] Walk the full outdoor loop: Common Ground → Outdoor → Beach → Hub → and back. All round-trips work.
